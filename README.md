# User Management App
 User Management App
 user can add using the required details and after submitting the details it navigates to users list.
 and we can see the users list and also multiple users can join.
 this user management app is build using React.js, Node.js, Express.js, and MongoDB.

Technologies used for
## Frontend
- React.js
- Vite
- Tailwind CSS

Technologies used for
## Backend
- Node.js
- Express.js
- MongoDB

## Features
- Add User
- View Users
- REST API
- Responsive UI
