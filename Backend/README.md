# Backend
Backend for User Management App
using Node.js, Express, and MongoDB.

## Features are
- Add User
- View Users
- REST API
- MongoDB Connection

## Packages Used
Install Express:
npm install express

Install Mongoose:
npm install mongoose

Install CORS:
npm install cors

Install Nodemon:
npm install nodemon

Install Dotenv:
npm install dotenv



### Backend Folder Structure

- APIs
  - userapi.js
- Models
  - UserModel.js
- node_modules
- .env
- package.json
- package-lock.json
- server.js


## To Run Project

npm install
npm nodemon server.js


## Environment Variables

env
PORT=5000
DB_URL=mongodb://127.0.0.1:27017/UserManagementApp
